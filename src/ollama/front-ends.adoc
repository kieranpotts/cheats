= Front-ends

== VS Code

Ollama includes a CLI wizard to configure VS Code to use Ollama as a local LLM provider. Run the following command and follow the prompts:

[source,sh]
----
ollama launch vscode
----

Alternatively, you can configure it manually. Confirm Ollama is running at http://localhost:11434/ (you should see "Ollama is running"), then open the model picker in the Copilot Chat panel. Your local models may already appear under the "Ollama" provider. If not, click *Add Models*, choose "Ollama", and enter `http://localhost:11434/`.

[NOTE]
====
Even when using local Ollama models in Copilot Chat, you still need to be logged into GitHub. For a fully offline experience, use a different front-end.
====

Other VS Code extensions that support Ollama as a back-end:

* https://marketplace.visualstudio.com/items?itemName=Continue.continue[Continue] — open source; supports chat, inline autocomplete, and code selection Q&A
* https://marketplace.visualstudio.com/items?itemName=saoudrizwan.claude-dev[Cline] — suited to multi-file and whole-repo changes; reads, writes, and navigates files autonomously
* https://marketplace.visualstudio.com/items?itemName=rjmacarthy.twinny[Twinny] — lightweight; focused on fast local autocomplete

== Claude Code

The quickest way to integrate Ollama into Claude Code CLI is to use Ollama's `launch` command, which will pass an inline configuration to Claude Code to connect it to the Ollama server:

[source,sh]
----
ollama launch claude
----

Claude will launch with the Ollama model you last selected. To choose a different model, reset the config by passing the `--config` flag:

[source,sh]
----
ollama launch claude --config
----

You can also pass in the name of any model listed in `ollama ls`:

[source,sh]
----
ollama launch claude --model gemma4:31b
----

If you want to make Ollama the default provider, and to set default models, add the following to your shell profile (`~/.bashrc`, `~/.zshrc`, etc.). The auth token can be any value – Ollama ignores it's value.

[source,sh]
----
export ANTHROPIC_BASE_URL=http://localhost:11434
export ANTHROPIC_AUTH_TOKEN=ollama
export ANTHROPIC_MODEL=qwen3-coder:30b
export ANTHROPIC_SMALL_FAST_MODEL=qwen2.5-coder:3b # For fast subtasks.
----

Restart your shell for the changes to take effect, then launch `claude` directly.

[WARNING]
======
These settings will also effect other Claude interfaces, such as the VS Code extension, effectively locking you out of access to Claude's hosted models.
======

== OpenCode

As before, the quickest way to configure OpenCode to integrate with your local Ollama server is to get Ollama to do the work for you:

[source,sh]
----
ollama launch opencode
----

Alternatively you can configure a custom integration at `~/.config/opencode/opencode.json`:

[source,json]
----
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "ollama": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Ollama (local)",
      "options": {
        "baseURL": "http://localhost:11434/v1"
      },
      "models": {
        "qwen3:8b-16k": { "tools": true }
      }
    }
  }
}
----

`@ai-sdk/openai-compatible` is the SDK package required to integrate with OpenAI API-compatible services (like Ollama). The `tools` option is what enables agentic file edits.

Restart OpenCode, run /models, and your local model should be there.

== Choosing models for tool integrations

When using Ollama with tools like VS Code's chat, the model selection dropdown only shows models that support function calling. If a model doesn't support tools, it won't appear in the list. For example, if you pull `deepseek-coder:6.7b`, it won't show up in VS Code's model selection panel because this model does not support tooling.

The best way to check for tool calling support is to look for a "tools" badge on the model's page in the Ollama library at ollama.com.

You can also use the `ollama show <model>` command in your terminal to check a model's capabilities.

== Command line interfaces

https://aider.chat/[Aider] works across a whole Git repository, similar to Claude Code or Copilot CLI. It connects to Ollama via its OpenAI-compatible endpoint.

[source,sh]
----
aider --model ollama_chat/qwen2.5-coder:7b
----

See the https://aider.chat/docs/llms/ollama.html[Aider + Ollama docs] for further instructions.

https://github.com/TheR1D/shell_gpt[ShellGPT] (sgpt) is a general-purpose tool for piping commands and text into a model. Useful for explaining errors and analyzing logs.

[source,sh]
----
sgpt --model ollama/mistral "explain this error: segfault at 0x00"
cat error.log | sgpt --model ollama/mistral "what's wrong here?"
----

https://github.com/danielmiessler/Fabric[Fabric] is built around reusable prompt templates. Works well with piped input.

[source,sh]
----
cat error.log | fabric --model ollama:mistral --pattern analyze_logs
git diff | fabric --model ollama:mistral --pattern write_commit
----

https://terminaltrove.com/oterm/[Oterm] is a terminal UI (TUI) that provides a more visually rich experience than plain CLI tools like Aider or sgpt.
