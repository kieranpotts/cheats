= Hardware

Ollama automatically uses GPU acceleration where available (NVIDIA via CUDA, AMD
via ROCm, Apple Silicon via Metal, and Intel plus additional AMD GPUs via Vulkan
on Windows and Linux). It falls back to CPU if no GPU is detected.

The primary constraint on performance is VRAM. Models that fit entirely in VRAM
run fast. Spilling a significant share of the layers into system RAM causes a
5–20x performance drop.

All figures assume Q4 quantization (4-bit precision), the Ollama default. Full
precision models require ~4x more memory. Memory needs scale with total
parameters, not active ones: a mixture-of-experts model such as Qwen3 235B-A22B
still needs all 235B of weights resident (~132 GB at Q4), despite activating
only 22B per token.

A model is a stack of layers, and each layer sits either in VRAM (computed by
the GPU) or in system RAM (computed by the CPU). Moving layers onto the GPU is
called _offloading_, and the `num_gpu` parameter sets how many layers to send
there — it is a layer count, not a count of GPUs:

* `-1` (the default) — Ollama measures free VRAM and picks the split itself.
* `0` — every layer on the CPU.
* `999` — force all layers onto the GPU, spread across all detected cards.

CAUTION: Ollama follows llama.cpp in using "offload" to mean offload _to_ the
GPU, so "100% GPU offload" is the fast, fully GPU-resident case. Elsewhere the
same word is often used to mean spilling _out of_ VRAM onto the CPU, which is
the slow case. Check which sense a given source intends.

Consumer GPU options, roughly in order of price:

* RTX 3090 (24 GB) — runs up to 34B models; 70B only with aggressive
  quantization. Available second-hand.
* Dual RTX 3090s (48 GB combined) — runs 70B models at Q4 (~16–21 tok/s);
  typically cheaper than a single RTX 5090.
* RTX 4090 (24 GB) — ~95–110 tok/s on 8B models.
* RTX 5090 (32 GB) — ~140 tok/s on 8B models.
* RTX 6000 Ada (48 GB) — unlocks 70B models comfortably.

NOTE: Published tokens-per-second figures vary by 40–50% between sources, since
context length, quantization, and inference engine all differ. Treat the numbers
above as short-context, batch-size-1 upper bounds.

Nvidia is recommended — its CUDA ecosystem has the most mature AI software
support. AMD is an alternative, via either ROCm or Vulkan, but lags in
performance and compatibility. Intel GPUs work through Ollama's Vulkan support;
Intel's own oneAPI path is not supported upstream, and is available only via
community builds.

TIP: Choose a motherboard with room for a second GPU later. The AMD Threadripper
platform is a good choice for dual-GPU or expandable builds.

== System RAM

Size system RAM to how much of the model lives on the GPU, not to the model's
size.

* *Model fits in VRAM.* 16 GB is workable and 32 GB is comfortable, even for
  32B models. RAM is not the constraint here.
* *Model overflows VRAM.* The spilled layers, and their KV cache, occupy system
  RAM for real. Size RAM to the overflow, and expect the 5–20x slowdown.
* *Deliberately running very large models on CPU.* 128–256 GB puts 100B+
  quantized models within reach, at a few tokens per second.

RAM is not needed only for the initial load. Ollama memory-maps the model file,
so a copy of the weights stays resident in the page cache even at 100% GPU
offload — this can look like tens of GB in `top`. It is file-backed and
reclaimable, though, so it is not a real requirement; it just makes reloads
fast.

The KV cache is separate again, and grows with both context length and
concurrency: required memory scales by `OLLAMA_NUM_PARALLEL` ×
`OLLAMA_CONTEXT_LENGTH`.

== CPU

Once the model is loaded into VRAM, the GPU handles 95% of the work. An Intel i5
or Ryzen 5 is sufficient; an i7 or Ryzen 7 is more than enough.

== Storage

A fast NVMe SSD (1–2 TB) is important. Models that fit a consumer GPU are 4–40
GB each, and load slowly from spinning disks. 100B+ models run to several hundred
GB apiece, so budget storage accordingly.

== PSU

Size to your GPU — 850W for a single RTX 3090/4090, 1000W+ for an RTX 5090, and
1200W+ for a dual-GPU build, which can draw ~900W under sustained load.

== Cooling and noise

Dual GPUs generate significant heat. Use a large case with good airflow and
large fans running at low speed to minimize noise.

== Case

For a modular, expandable AI workstation: full tower or rack-convertible.
Options include the Fractal Design Define 7 XL, Corsair 1000D, and SilverStone
RM51 (a 5U rack-mount chassis that can be tilted for use as a tower, with 455 mm
of GPU clearance).

== OS

Mainstream Linux distributions are recommended — driver support is excellent and
Ollama runs natively with full CUDA acceleration.
