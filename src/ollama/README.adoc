= Ollama

Ollama is a tool for downloading and running open-weight large language models
locally. It provides a simple CLI and a local HTTP API, and handles model
storage, hardware acceleration, and inference.

Ollama also offers a [cloud service](https://docs.ollama.com/cloud) that
provides access to hosted models via the same local HTTP API server (or via
direct HTTP requests to the cloud API). This means you can use the same tools
and interfaces to access both local and hosted models, and switch between them
seamlessly.
