# Prompts

In Pi, prompts are expanded from slash commands. They are great choice or recurring project tasks like: review, refactor, issue triage.

Install at `.pi/prompts/<prompt>.md`. Template:

[source,markdown]
----
---
name: proofread
description: Proofread each AsciiDoc file and open one PR per file
argument-hint: "[glob]"
---

# Proofread

Proofread the AsciiDoc files in this repository, opening one pull request per file.

## Instructions

...
----

To execute: `/proofread <glob>`.
