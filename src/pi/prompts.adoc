= Prompts

In Pi, prompts are expanded from slash commands. They're a great choice for
recurring project tasks like review, refactor, issue triage. They're plain
Markdown text-expansion - lighter than link:./skills.adoc[skills], whose
instructions only load on-demand.

== Locations

Pi discovers prompt templates from:

- Global: `~/.pi/agent/prompts/*.md`
- Project: `.pi/prompts/*.md`
- Packages: `prompts/` directories
- Settings: the `prompts` array
- CLI: `--prompt-template <path>`

The filename (minus `.md`) becomes the command name - `review.md` -> `/review`.

== Template

[source,markdown]
----
---
name: proofread
description: Proofread each AsciiDoc file and open one PR per file
argument-hint: "[glob]"
---

# Proofread

Proofread the AsciiDoc files in this repository, opening one pull request per file.

## Instructions

...
----

== Arguments

Templates take positional and combined arguments:

- `$1`, `$2`, ...: positional.
- `$@` / `$ARGUMENTS`: all arguments.
- `${@:N}` / `${@:N:L}`: a slice.

To execute: `/proofread <glob>`, or eg. `/component Button "click handler"`.
