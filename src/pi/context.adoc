= Context

Pi builds the prompt as a stack:

- Default prompt (can be overridden with a custom `SYSTEM.md` file).
- `APPEND_SYSTEM.md`
- `AGENTS.md` / `CLAUDE.md`
- Skills list.
- Date + working dir.

Examples of files that mutate the context:

- Global: `~/.pi/agent/AGENTS.md`
- Project tree: `AGENTS.md` or `CLAUDE.md`
- Replacement system prompt: `.pi/SYSTEM.md`
- Appended system prompt: `.pi/APPEND_SYSTEM.md`
