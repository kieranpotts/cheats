= Skills

In Pi, skills and prompts serve different purposes.

Skills are intended for reusable capability packaging: workflows, setup, scripts, references. Pi loads into context the descriptions for all the skills it has auto-discovered, then it dynamically loads the full skill instructions on-demand.

To explicitly load a skill:

----
/skill:brave-search
/skill:pdf-tools extract
----

Note that parameters can be passed to the skill.

== Locations

Pi will look for skills in both the current project and the user's home directory in the paths `.pi/skills/` and `.agents/skills`. If you want Pi to auto-discover skills in other paths, adjust your `settings.json`:

[source,json]
----
{
  "skills": ["../path/to/skills"]
}
----
