= Skills

In Pi, skills and prompts serve different purposes.

Skills are self-contained capability packages the agent loads on-demand: workflows, setup instructions, helper scripts, references. Only each skill's *description* sits in the system prompt. Pi loads the full instructions on-demand when it judges the skill relevant (progressive disclosure).

== Invoking

The agent can load a skill itself, or you can load one explicitly:

----
/skill:brave-search
/skill:pdf-tools extract
----

Parameters can be passed to the skill. The `/skill:` commands require `"enableSkillCommands": true` (set it via `/settings` or `settings.json`).

== Locations

Pi auto-discovers skills from:

- Global: `~/.pi/agent/skills/` and `~/.agents/skills/`
- Project: `.pi/skills/` and `.agents/skills/`
- Packages: `skills/` directories
- Settings: the `skills` array
- CLI: `--skill <path>`

To add other paths, adjust `settings.json`:

[source,json]
----
{
  "skills": ["../path/to/skills"]
}
----

== SKILL.md frontmatter

[source,yaml]
----
---
name: pdf-tools          # 1-64 chars; lowercase letters, numbers, hyphens
description: ...         # up to 1024 chars: what it does and when to use it
---
----

Optional fields: `license`, `compatibility`, `metadata`, `allowed-tools`, `disable-model-invocation`.
