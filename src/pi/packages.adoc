= Packages

Packages bundle link:./extensions.adoc[extensions], link:./skills.adoc[skills],
link:./prompts.adoc[prompt templates], and link:./themes.adoc[themes] for
sharing. They're distributed via npm, git, or local paths.

[WARNING]
====
Pi packages run with full system access. Extensions execute arbitrary code, and
skills can instruct the model to run any executable. Review the source before
installing third-party packages.
====

== Commands

[cols="1,3", options="header"]
|===
| Command | Description
| `pi install npm:@scope/pkg@1.2.3` | Install from npm.
| `pi install git:github.com/user/repo@v1` | Install from a git repo.
| `pi install ./path` | Install from a local directory.
| `pi install ... -l` | Install into the project (`.pi/`) rather than globally.
| `pi remove <package>` | Uninstall.
| `pi list` | List installed packages.
| `pi update` | Update Pi and all packages.
| `pi -e <source>` | Try a package temporarily, without installing.
|===

== Discovery and authoring

The gallery at https://pi.dev/packages[pi.dev/packages] lists packages tagged
`pi-package`. To author one, declare resources under a `pi` key in
`package.json`, or use the convention directories `extensions/`, `skills/`,
`prompts/`, `themes/`.

Installed resources live in `~/.pi/agent/` (global) or `.pi/` (project).
