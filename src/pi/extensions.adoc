= Extensions

Pi is highly extensible. Through extensions you can add to Pi:

* Tools – LLM-callable functions.
* Commands – your own /command flows.
* Events – intercept turns and tools.
* State – control session persistence.
* Providers – dynamic model sources.
* UI – prompts, confirms, widgets.

Ready-made extensions can be downloaded from pi.dev/packages.

There are example extensions here:
https://github.com/earendil-works/pi/blob/main/packages/coding-agent/examples/extensions/README.md
