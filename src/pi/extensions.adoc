= Extensions

Pi is highly extensible. Extensions are TypeScript modules (compiled natively via jiti). Through them you can add to Pi:

* Tools – LLM-callable functions.
* Commands – your own /command flows.
* Events – intercept turns and tools (session start, tool calls, message updates, ...).
* State – control session persistence.
* Providers – dynamic model sources.
* UI – prompts, confirms, notifications, widgets, shortcuts.

Common uses: permission gates, path protection, custom compaction, interactive workflows, external integrations.

== Writing and installing

Extensions are auto-discovered in:

- Global: `~/.pi/agent/extensions/`
- Project: `.pi/extensions/`

Each exports a default factory function that receives the `ExtensionAPI`. Try one without installing using `pi -e ./path.ts`.

Key API points: tool registration (name, description, Typebox params, async `execute`); UI via `ctx.ui.confirm()` / `ctx.ui.select()` / `ctx.ui.notify()`; shell via `pi.exec()`; state via `pi.appendEntry()`; session control (in commands) via `ctx.newSession()` / `ctx.fork()` / `ctx.switchSession()`.
