= Pi CLI reference

== Startup flags

[source,sh]
----
pi ...
----

[cols="1,3" options="header"]
|===
| Flag | Description
| `-c` | Continue the most recent session.
| `-r` | Browse previous sessions.
| `--name "name"` | Set the session display name at startup.
| `--session <path\|id>` | Open a specific session.
| `--fork <path\|id>` | Fork a session into a new one.
| `--no-session` | Ephemeral mode - nothing is saved. Useful for running `pi` programmatically from scripts.
| `-p "prompt"` | One-shot mode: run the prompt and exit. Useful for scripting.
| `--mode json` | Output events as JSON.
| `--mode rpc` | Enable RPC mode for process integration.
| `--provider <name>` | Override the provider.
| `--model <pattern>` | Override the model (matches `provider/id`, supports `:thinking`).
| `--thinking <level>` | `off`, `minimal`, `low`, `medium`, `high`, `xhigh`.
| `--tools <list>` | Allow only these tools.
| `--exclude-tools <list>` | Disable these tools.
| `--no-tools` | Disable all tools.
|===

== File handling

Pass files to the model using the `@` symbol:

* `pi @README.md "Summarize this"`
* `pi @src/app.ts @src/app.test.ts "Review these together"`
* `pi -p @screenshot.png "Analyze this"`
