= `pass` (The Standard Unix Password Manager)

`pass` is the standard unix password manager. It stores passwords in GPG-encrypted files. It's particularly handy for storing personal access tokens and similar secrets locally, securely.

See https://www.passwordstore.org/ for more details.

== Quick start

* *Initialize password store:* `pass init <gpg-id>`
* *Insert/Update password:* `pass insert <folder/name>`
* *Retrieve password:* `pass <folder/name>` (prints to stdout)
* *Copy password to clipboard:* `pass -c <folder/name>`
* *List passwords:* `pass`
* *Remove password:* `pass rm <folder/name>`
* *Generate password:* `pass generate <folder/name> <length>`

== Common patterns

* *Organization:* Passwords are stored in a hierarchical structure (e.g., `pass social/twitter`).
* *Multi-line data:* Use `pass insert --multiline <name>` to store usernames, URLs, and notes alongside the password.
* *Git Integration:* `pass` integrates natively with Git for synchronization across machines.
  * `pass git init`
  * `pass git push`
  * `pass git pull`

== Useful options

[cols="1,3", options="header"]
|===
| Flag | Description
| `-c, --clip` | Copy password to clipboard (clears after timeout)
| `-d, --downcase` | Downcase the password
| `-g, --generate` | Generate a random password
| `--help` | Display help
|===
