= `unzip`

The `unzip` command extracts files from a ZIP archive.

.Example: extract an archive into the current directory
----
unzip archive.zip
----

.Example: extract into a specific directory
----
unzip archive.zip -d /path/to/dir
----

.Example: list the contents of an archive without extracting
----
unzip -l archive.zip
----

See also `zip`, for creating ZIP archives.
