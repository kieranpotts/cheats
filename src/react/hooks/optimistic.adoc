= React hooks: Optimistic updates

_Added in React 19._

`useOptimistic` provides a simple way to implement _optimistic updates_. The UI
changes straight away, before an async operation, such as a network request,
has completed.

Optimistic updates make an app feel faster and more responsive. The user sees
the result of their action immediately, rather than waiting for a response
from the server.

== Understanding useOptimistic

[source,js]
----
const [optimisticState, setOptimistic] = useOptimistic(value, reducer)
----

`useOptimistic` takes two arguments.

1. *Value.* The real value, eg. from state or props. React shows it when no
   Action is pending.

2. *Reducer.* Optional. A pure function, `(currentState, action) => nextState`,
   that computes the optimistic state from the current state and the argument
   passed to `setOptimistic`.

The Hook returns an array of two elements.

1. *Optimistic state.* While an Action is pending, it is the value set by
   `setOptimistic`, or computed by the reducer. Otherwise, it equals `value`.

2. *Setter function.* Sets the optimistic state. With no reducer, it takes the
   new value, or an updater function. With a reducer, it takes the action to
   pass to the reducer.

When the Action finishes, React discards the optimistic state, and shows
`value` again. If the Action updated the real state, `value` now holds the
result. If the Action failed, and didn't update the real state, the UI returns
to how it was before.

[IMPORTANT]
====
Call the setter inside an Action, ie. inside `startTransition`, or inside a
function passed to an action prop such as `<form action>`. Outside an Action,
React logs a warning, and the optimistic state appears only briefly.
====

== Example: A like button

Without a reducer, the setter takes the optimistic value directly.

[source,jsx]
----
import { startTransition, useOptimistic } from "react"

function LikeButton({ isLiked, onToggleLike }) {
  const [optimisticIsLiked, setOptimisticIsLiked] = useOptimistic(isLiked)

  function handleClick() {
    startTransition(async () => {
      setOptimisticIsLiked(!optimisticIsLiked)
      await onToggleLike()
    })
  }

  return (
    <button onClick={handleClick}>
      {optimisticIsLiked ? "♥ Liked" : "♡ Like"}
    </button>
  )
}
----

== Example: A todo list with optimistic updates

First, here is a basic todo list _without_ optimistic updates. The new todo
item appears only after the API call completes.

[source,jsx]
----
import { startTransition, useState } from "react"

async function addTodoToAPI(text) {
  await new Promise(resolve => setTimeout(resolve, 1000))
  return { id: crypto.randomUUID(), text }
}

export function TodoList() {
  const [todos, setTodos] = useState([])

  async function addTodo(formData) {
    const savedTodo = await addTodoToAPI(formData.get("todo"))

    /* State updates after an `await` need their own `startTransition`. */
    startTransition(() => {
      setTodos(currentTodos => [...currentTodos, savedTodo])
    })
  }

  return (
    <div>
      <form action={addTodo}>
        <input type="text" name="todo" />
        <button type="submit">Add Todo</button>
      </form>
      <ul>
        {todos.map(todo => (
          <li key={todo.id}>{todo.text}</li>
        ))}
      </ul>
    </div>
  )
}
----

Now the same component with `useOptimistic`. The new todo item appears
immediately, with reduced opacity to show that it is pending. When the API call
completes, the saved todo item replaces the optimistic one.

[source,jsx]
----
import { startTransition, useOptimistic, useState } from "react"

async function addTodoToAPI(text) {
  await new Promise(resolve => setTimeout(resolve, 1000))
  return { id: crypto.randomUUID(), text }
}

export function TodoList() {
  const [todos, setTodos] = useState([])
  const [optimisticTodos, addOptimisticTodo] = useOptimistic(
    todos,
    (currentTodos, newTodo) => [
      ...currentTodos,
      { ...newTodo, pending: true }
    ]
  )

  async function addTodo(formData) {
    const text = formData.get("todo")

    /* A temporary ID, so each optimistic item has a unique key. */
    addOptimisticTodo({ id: crypto.randomUUID(), text })

    const savedTodo = await addTodoToAPI(text)
    startTransition(() => {
      setTodos(currentTodos => [...currentTodos, savedTodo])
    })
  }

  return (
    <div>
      <form action={addTodo}>
        <input type="text" name="todo" />
        <button type="submit">Add Todo</button>
      </form>
      <ul>
        {optimisticTodos.map(todo => (
          <li
            key={todo.id}
            style={{ opacity: todo.pending ? 0.5 : 1 }}
          >
            {todo.text}
          </li>
        ))}
      </ul>
    </div>
  )
}
----

The reducer receives the _latest_ list of todos. If the real list changes while
the Action is pending, the optimistic item is added to the new list, not an
outdated copy.
