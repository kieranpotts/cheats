= React hooks: Form status

_Added in React 19._

`useFormStatus` lets a component inside a `<form>` read the form's submission
status, without the form passing it down as props or through context.

This is particularly useful when a form is built from separate components. For
example, a submit button in its own component can disable itself while the form
submits, without the parent form passing down a `pending` prop.

== Understanding useFormStatus

`useFormStatus` is imported from `react-dom`, not `react`. It takes no
arguments, and returns an object with the following properties.

* `pending` is `true` while the parent `<form>` is submitting, and `false`
  otherwise.

* `data` is the `FormData` that the parent `<form>` is submitting. It is
  `null` when there is no submission in progress.

* `method` is the HTTP method of the form, `"get"` or `"post"`.

* `action` is the function passed to the form's `action` prop. It is `null` if
  the action is a URL, or if there is no parent `<form>`.

[source,jsx]
----
import { useFormStatus } from "react-dom"

function SubmitButton() {
  const { pending } = useFormStatus()

  return (
    <button type="submit" disabled={pending}>
      {pending ? "Submitting…" : "Submit"}
    </button>
  )
}

export function FeedbackForm() {
  async function submitFeedback(formData) {
    await sendFeedback(formData.get("text"))
  }

  return (
    <form action={submitFeedback}>
      <input type="text" name="text" />
      <SubmitButton />
    </form>
  )
}
----

[IMPORTANT]
====
`useFormStatus` MUST be called from a component that renders inside a
`<form>`. It reads the status of the nearest parent `<form>` only. It doesn't
report on a `<form>` that the same component renders.

The form's `action` MUST be a function. React can't track the status of a form
whose action is a URL, because the browser submits that form with a full page
navigation.
====
