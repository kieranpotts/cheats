= React custom components

At the simplest level, a React component is a JavaScript function that returns
JSX.

[source,jsx]
----
function MyComponent() {
  return <h1>Hello, world!</h1>
}
----

To render a component, use it as a JSX tag. Don't call it as a plain function,
eg. `MyComponent()`. React then treats the result as part of the caller, so the
component's Hooks belong to the caller, and the component can't have state of
its own.

[source,jsx]
----
import { createRoot } from "react-dom/client"

createRoot(document.getElementById("root")).render(<MyComponent />)
----

Component names MUST start with a capital letter. JSX treats lowercase tags,
such as `<header>`, as HTML elements, and capitalized tags, such as
`<Header>`, as components.

A single component can render a whole page.

[source,jsx]
----
function Page() {
  return (
    <div>
      <header>
        <nav>
          <img src="./my-logo.png" alt="My site" />
        </nav>
      </header>
      <h1>Hello, world!</h1>
      <p>This is my new home page.</p>
      <footer>
        <small>© 2026 …</small>
      </footer>
    </div>
  )
}
----

But the real power of React comes from _composing_ complex user interfaces
from lots of small, reusable components.

[source,jsx]
----
function Header() {
  return (
    <header>
      <nav>
        <img src="./my-logo.png" alt="My site" />
      </nav>
    </header>
  )
}

function Footer() {
  return (
    <footer>
      <small>© 2026 …</small>
    </footer>
  )
}

function MainContent() {
  return (
    <main>
      <h1>Hello, world!</h1>
      <p>This is my new home page.</p>
    </main>
  )
}

function Page() {
  return (
    <>
      <Header />
      <MainContent />
      <Footer />
    </>
  )
}
----

Components SHOULD be extracted into separate files, and imported into the
components that depend on them. A file can have one default export and any
number of named exports.

[source,jsx]
----
/* Header.jsx: default export. */
export default function Header() {
  // …
}

/* Footer.jsx: named export. */
export function Footer() {
  // …
}

/* Page.jsx */
import Header from "./Header"
import { Footer } from "./Footer"
import MainContent from "./MainContent"

export default function Page() {
  return (
    <>
      <Header />
      <MainContent />
      <Footer />
    </>
  )
}
----

== Keep components pure

Rendering MUST be pure. Given the same props, state, and context, a component
MUST return the same JSX. It MUST NOT change variables or objects that existed
before it was called. Put side effects in event handlers, or, as a last resort,
in Effects.

[source,jsx]
----
/* ✅ Pass the value in as a prop. */
function Cup({ guest }) {
  return <h2>Tea cup for guest #{guest}</h2>
}

/* ❌ Changes a variable outside the component during render. */
let guest = 0

function Cup() {
  guest = guest + 1
  return <h2>Tea cup for guest #{guest}</h2>
}
----

In development, Strict Mode calls each component twice to help find impure ones.
The React Compiler also depends on components being pure.

== Define components at the top level

Don't define a component inside another component.

[source,jsx]
----
/* ✅ Defined once, at the top level of the module. */
function Header() {
  // …
}

function Page() {
  return <Header />
}

/* ❌ `Header` is a new component type on every render of `Page`. React
unmounts and remounts it each time, which resets its state. */
function Page() {
  function Header() {
    // …
  }

  return <Header />
}
----
