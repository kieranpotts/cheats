= Prototyping React apps

You can prototype a React interface in a single HTML file, with no build step.

React 19 no longer publishes UMD builds, which were the `<script>` files that
put a global `React` object on the page. Instead, load React as ES modules from
a CDN such as esm.sh, and map the package names to the CDN URLs with an import
map. To use JSX, load Babel from a CDN as well. It compiles each
`<script type="text/babel">` in the browser.

.index.html
[source,html]
----
<!doctype html>
<html lang="en">
  <head>
    <meta charset="utf-8" />
    <script type="importmap">
      {
        "imports": {
          "react": "https://esm.sh/react@19.3.0?dev",
          "react-dom/client": "https://esm.sh/react-dom@19.3.0/client?dev"
        }
      }
    </script>
    <script src="https://unpkg.com/@babel/standalone@7/babel.min.js"></script>
  </head>
  <body>
    <div id="root"></div>

    <!-- `data-type="module"` lets the script use `import`. -->
    <!-- `data-presets="react"` compiles only the JSX. -->
    <script type="text/babel" data-type="module" data-presets="react">
      /* Babel 7 compiles JSX to `React.createElement()` calls, so `React`
      must be in scope. */
      import React, { useState } from "react"
      import { createRoot } from "react-dom/client"

      function Counter() {
        const [count, setCount] = useState(0)

        return (
          <button onClick={() => setCount(count + 1)}>
            Clicked {count} times
          </button>
        )
      }

      createRoot(document.getElementById("root")).render(<Counter />)
    </script>
  </body>
</html>
----

Serve the file from a local web server, eg. `npx serve`, and open it in a
browser.

The `?dev` query loads React's development build, which has extra warnings and
checks. Pin the same version for every React package, so the page loads only
one copy of React.

[IMPORTANT]
====
This method MUST NOT be used in production. It is slow, because it compiles JSX
at runtime, and it is not secure, because it runs code loaded directly from
third-party servers. For anything beyond a prototype, use a build tool or
framework.
====
