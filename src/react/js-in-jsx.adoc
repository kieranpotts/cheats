= JS in JSX

JSX can embed any JavaScript expression in curly braces. A lot of the tricks in
React components are plain JavaScript inside JSX.

== Conditional rendering

Use the `&&` operator to render an element only when a condition is true.

[source,jsx]
----
export default function Joke(props) {
  return (
    <div>
      {props.title && <h3>{props.title}</h3>}
      <p>Punchline: {props.punchline}</p>
      <hr />
    </div>
  )
}
----

React renders nothing for `false`, `true`, `null`, and `undefined`. But it does
render `0` and `NaN`. Make sure the left side of `&&` is a boolean.

[source,jsx]
----
/* ✅ Renders nothing when the list is empty. */
{messages.length > 0 && <MessageList messages={messages} />}

/* ❌ Renders "0" when the list is empty. */
{messages.length && <MessageList messages={messages} />}
----

Use the ternary operator to choose between two elements.

[source,jsx]
----
function Card(props) {
  return (
    <div className="card">
      {props.availableStock === 0
        ? <div className="card--badge">SOLD OUT</div>
        : <div className="card--badge">AVAILABLE</div>}
      <img src={`../images/${props.img}`} className="card--image" alt="" />
      {/* More card content */}
    </div>
  )
}
----

For more complex logic, compute the value in plain JavaScript before the
`return`, or return early.

[source,jsx]
----
function Item({ name, isPacked }) {
  if (isPacked) {
    return <li className="item">{name} ✅</li>
  }

  return <li className="item">{name}</li>
}
----

== Comments

HTML comments, `<!-- … -->`, are a syntax error in JSX. Use a JavaScript block
comment inside curly braces instead.

[source,jsx]
----
<div>
  {/* This is a comment. */}
</div>
----

== Inline styles

The `style` prop takes an object, not a string. Property names use camelCase,
eg. `backgroundColor`. The double braces serve different purposes. The outer
braces mark a JavaScript expression in JSX. The inner braces are the object
literal.

[source,jsx]
----
export default function Joke(props) {
  return (
    <div>
      <h3 style={{ display: props.title ? "block" : "none" }}>{props.title}</h3>
      <p>Punchline: {props.punchline}</p>
      <hr />
    </div>
  )
}
----

React adds `px` to numeric values for most properties, eg.
`style={{ width: 100 }}` sets `width: 100px`.

== String interpolation

Use template literals to build string values.

[source,jsx]
----
return (
  <img src={`../images/${props.img}`} className="card--image" alt="" />
)
----

== Rendering arrays

An embedded expression can be a string, a number, a JSX element, or an array of
these. React renders each item of an array in turn. A plain object can't be
rendered, and React throws an error if you try.

The following example renders "12345".

[source,jsx]
----
export default function App() {
  const numbers = ["1", "2", "3", "4", "5"]

  return (
    <div>
      {numbers}
    </div>
  )
}
----

To render a component for each item, map the data to an array of JSX elements.

[source,jsx]
----
export default function App() {
  const jokeElements = jokesData.map(joke => {
    return <Joke key={joke.id} setup={joke.setup} punchline={joke.punchline} />
  })

  return (
    <div>
      {jokeElements}
    </div>
  )
}
----

Each element in the array needs a `key` prop that is unique among its siblings.
