= AWS: Security management services

The following services help you to manage security in your AWS environments.

== AWS Security Hub

* Provides a comprehensive view of security alerts and security posture across
  your AWS accounts.
* Aggregates, organizes, and prioritizes security alerts (or findings) from
  multiple AWS services.
* Continuously monitors your environment using automated security checks.
* You can configure security standards to validate your environments against,
  including:

** AWS Foundational Security Best Practices
** CIS AWS Foundations Benchmark (now on v3.0.0, up from the original v1.2.0/
   v1.4.0)
** PCI DSS v4.0/v4.0.1 (v3.2.1 was retired industry-wide in 2024)

NOTE: Check the Security Hub console for the current list and versions of
supported standards — these are periodically updated by AWS and by the
standards bodies themselves.

== AWS Security Bulletins

* Security and privacy events affecting AWS services.
* Published on a web page, and also available via RSS feed.

== Responding to a suspected account compromise

If you suspect your AWS account or credentials have been compromised, AWS's
recommended incident-response steps are:

* Rotate the root user's password immediately, and confirm MFA is (still)
  enabled on the root user.
* Rotate/deactivate the credentials (passwords and access keys) of any IAM
  users or roles that may have been affected.
* Identify and delete/terminate any unauthorized resources that were created
  by the attacker (eg. rogue EC2 instances, often used for cryptomining).
* Review CloudTrail for the full history of what the compromised credentials
  were used to do.
* Contact AWS Support if you need help, especially if unexpected charges have
  been incurred as a result of the compromise.

== AWS Trust & Safety Team

You should contact the AWS Trust & Safety Team if you find AWS resources that
are being used for:

* Spam
* Port scanning
* Denial of Service (DoS) attacks
* Intrusion attempts
* Hosting of objectionable or copyrighted content

Their email address is abuse@amazonaws.com.
