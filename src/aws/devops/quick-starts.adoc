= AWS Quick Starts

CAUTION: The Quick Starts program has been discontinued and superseded by the
*AWS Solutions Library*, which now hosts the equivalent reference
deployments/guidance. Treat this entry as historical context rather than a
description of a current, actively-maintained AWS offering.

*AWS Quick Starts* were built by AWS solutions architects and partners to help
you deploy popular technologies on AWS, based on AWS best practices for security
and high availability.

These accelerators reduce hundreds of manual procedures into just a few steps,
so you can build your production environment quickly and start using it
immediately.

Each Quick Start includes AWS CloudFormation templates that automate the
deployment and a guide that discusses the architecture and provides step-by-step
deployment instructions.
