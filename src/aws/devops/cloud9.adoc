= AWS Cloud9

CAUTION: Cloud9 has been closed to new customers since July 25, 2024. AWS is
not adding new features and is steering users towards CloudShell, IDE toolkits
(eg. the AWS Toolkit for VS Code/JetBrains), or Kiro. Existing Cloud9
environments continue to work, but don't plan new work around this service.

*AWS Cloud9* is a *cloud IDE* used to write, run, and debug code.

It has all the features of modern IDEs, including syntax highlighting, code
completion, debugging, error checking, and a built-in terminal.

It also provides collaborative features, enabling multiple developers to work on
the same codebase simultaneously.

As you'd expect, it integrates with lots of AWS services, including Lambda, Ec2,
and CodePipeline.
