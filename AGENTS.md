# Cheats

This repository is a collection of personal cheat sheets and study notes for
various tools, technologies, and languages.

The capitalized words REQUIRED, MUST, MUST NOT, RECOMMENDED, SHOULD,
SHOULD NOT, OPTIONAL, and MAY are to be interpreted as described in
[IETF RFC 2119](https://www.ietf.org/rfc/rfc2119.txt).

## Tech stack

- AsciiDoc files in a directory structure.

## Project structure

- **`src/`** Source files.

  - **`aws/`** AWS-related notes.

  - **`bash/`** Bash-related notes.

  - **`python/`** Python-related notes.

  - Etc.

- **`template/`** Template files for new collections notes.

## Tools

None.

## Rules

- MUST write in American English.

- MUST follow the template structure.

- MUST write valid AsciiDoc syntax.

- Text files MUST have `.adoc` file extension.
